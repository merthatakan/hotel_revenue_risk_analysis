# hotel revenue risk analysis
This repository contains a comprehensive **Business Intelligence (BI)** framework designed to mitigate operational risks in the hospitality sector. The project focuses on quantifying the financial impact of booking cancellations  and establishing data-driven thresholds for risk management.

## Strategic Objectives
The primary goal of this analysis is to evaluate how **Lead Time**  influences cancellation probability. By identifying critical "break points" in the booking lifecycle, the model provides actionable insights for:
•  Optimizing non-refundable pricing strategies.

• Reducing revenue leakage through automated risk assessment.

• Enhancing cash flow stability via personalized customer engagement metrics.

##  Technical Implementation
•   **Statistical Outlier Detection:** Utilizing NumPy for dynamic risk thresholding based on  calculations.

•  **Data Normalization:** Automated pre-processing of categorical room types and financial data types using Pandas.

•  **Executive Dashboarding:** Implementation of high-fidelity visualizations including Scatter Plots with multidimensional scaling, Revenue Pie Charts, and Segment-based Box Plots using **Seaborn**.

### Key Performance Indicators (KPIs) Analyzed:
• **Realized Revenue:** Total income from confirmed stays.

• **Opportunity Cost:** Quantified financial loss attributed to canceled reservations.

• **Risk Threshold:** The calculated "point of no return" for booking stability (75+ Days).
